## 1. 概述

### 1.1 卡片 2.0 简介

飞书互动卡片 2.0 是一种结构化的消息格式，支持丰富的交互元素，包括文本、图片、按钮、表单等。卡片 2.0 使用 JSON 格式定义，通过 `schema: "2.0"` 标识版本。

### 1.2 注意事项

**客户端版本要求**：

- 卡片 JSON 2.0 结构支持飞书客户端 7.20 及之后版本
- 当使用 JSON 2.0 结构的卡片发送至低于 7.20 版本的客户端时，卡片标题可正常显示，但内容将展示兜底的升级提示文案

**元素数量限制**：

- 一张卡片最多支持 200 个元素（如 `tag` 为 `plain_text` 的文本元素）或组件

**嵌套层级限制**：

- 容器类组件最多支持嵌套五层组件
- 建议避免多层嵌套，会压缩内容的展示空间，影响卡片的展示效果

**共享卡片限制**：

- 卡片 JSON 2.0 结构暂时仅支持共享卡片，不支持独享卡片配置
- 即 `update_multi` 参数仅支持设为 `true`

**交互有效期变更**（与 1.0 的差异）：

- **1.0 结构**：发出卡片的可交互时间为 30 天，可更新时间为 14 天（如果在第 14-30 天交互卡片，且交互回调动作为更新卡片，更新动作将不会生效）
- **2.0 结构**：卡片可交互和可更新时间统一为 **14 天**

**属性校验变更**（与 1.0 的差异）：

- **1.0 结构**：传入不支持的属性作忽略处理
- **2.0 结构**：传入不支持的属性将**报错**

**兜底高度变更**（与 1.0 的差异）：

- **1.0 结构**：卡片兜底高度为 24px
- **2.0 结构**：卡片兜底高度为 **40px**

**废弃组件说明**：

- 2.0 结构不再支持**备注（note）组件**和**交互模块**（`"tag": "action"`）
- 备注组件可由普通文本组件配置 `notation` 字号、`grey` 字体颜色、`icon` 属性替代
- 交互模块可由按钮（button）或折叠按钮组（overflow）组件配置合适的组件间距替代

### 1.3 组件分类

飞书卡片 2.0 的组件按照官方文档分为三大类：

**容器类组件（4个）**：
- 分栏（column_set）：用于多列布局
- 表单容器（form）：用于表单数据收集
- 交互容器（interactive_container）：支持内嵌组件并统一定义样式和交互能力
- 折叠面板（collapsible_panel）：支持折叠次要信息

**展示类组件（11个）**：
- 标题（header）：卡片标题组件
- 普通文本（div）：普通文本组件
- 富文本（markdown）：支持 Markdown 语法的富文本组件
- 图片（img）：图片展示组件
- 多图混排（img_combination）：多张图片混排展示
- 人员（person）：单个人员信息展示
- 人员列表（person_list）：多个人员信息展示
- 图表（chart）：数据可视化图表
- 表格（table）：表格数据展示
- 分割线（hr）：内容分割线

**交互类组件（12个）**：
- 输入框（input）：文本输入组件
- 按钮（button）：按钮交互组件
- 折叠按钮组（overflow）：折叠式按钮组
- 下拉选择-单选（select_static）：单选下拉选择器
- 下拉选择-多选（multi_select_static）：多选下拉选择器
- 人员选择-单选（select_person）：单选人员选择器
- 人员选择-多选（multi_select_person）：多选人员选择器
- 日期选择器（date_picker）：日期选择组件
- 时间选择器（picker_time）：时间选择组件
- 日期时间选择器（picker_datetime）：日期时间选择组件
- 多图选择（select_img）：图片选择组件
- 勾选器（checker）：勾选交互组件

### 1.4 卡片层级结构

```
Card (卡片)
├── config (配置)
├── header (头部)
├── body (主体)
│   └── elements[] (元素列表)
│       ├── div (容器)
│       ├── button (按钮)
│       ├── column-set (分栏)
│       ├── form (表单)
│       ├── input (输入框)
│       ├── select (选择器)
│       ├── datepicker (日期选择器)
│       ├── checkbox (勾选框)
│       ├── img (图片)
│       ├── markdown (Markdown 文本)
│       └── plain_text (纯文本)
└── fallback (降级内容)
```

## 2. 卡片根结构

### 2.1 Card (卡片根对象)

| 字段          | 类型   | 必填 | 说明                                 |
| ------------- | ------ | ---- | ------------------------------------ |
| `schema`    | string | 是   | 卡片 JSON 结构版本，固定为 `"2.0"` |
| `config`    | object | 否   | 卡片配置                             |
| `card_link` | object | 否   | 卡片链接配置                         |
| `header`    | object | 否   | 卡片头部                             |
| `body`      | object | 是   | 卡片主体                             |
| `fallback`  | object | 否   | 降级配置                             |

**JSON 示例**:

```json
{
  "schema": "2.0",
  "config": {
    "update_multi": true
  },
  "header": {
    "title": {
      "tag": "plain_text",
      "content": "卡片标题"
    }
  },
  "body": {
    "elements": [
      {
        "tag": "plain_text",
        "content": "卡片内容"
      }
    ]
  }
}
```

### 2.2 Config (卡片配置)

`config` 用于配置卡片的全局行为，包括流式更新模式、是否允许被转发、是否为共享卡片等。

| 字段                           | 类型     | 必填 | 默认值      | 说明                                                 |
| ------------------------------ | -------- | ---- | ----------- | ---------------------------------------------------- |
| `streaming_mode`             | boolean  | 否   | `false`   | 卡片是否处于流式更新模式                             |
| `streaming_config`           | object   | 否   | -           | 流式更新配置                                         |
| `summary`                    | object   | 否   | -           | 卡片摘要信息，自定义客户端聊天栏消息预览中的展示文案 |
| `locales`                    | string[] | 否   | -           | 指定生效的语言列表（JSON 2.0 新增属性）              |
| `enable_forward`             | boolean  | 否   | `true`    | 是否支持转发卡片                                     |
| `update_multi`               | boolean  | 否   | `true`    | 是否为共享卡片（JSON 2.0 暂时仅支持设为 `true`）   |
| `width_mode`                 | string   | 否   | `default` | 卡片宽度模式：`default`/`compact`/`fill`       |
| `use_custom_translation`     | boolean  | 否   | `false`   | 是否使用自定义翻译数据                               |
| `enable_forward_interaction` | boolean  | 否   | `false`   | 转发的卡片是否仍然支持回传交互                       |
| `style`                      | object   | 否   | -           | 自定义字号和颜色配置                                 |

**streaming_config (流式更新配置)**:

| 字段                   | 类型   | 说明                                                  |
| ---------------------- | ------ | ----------------------------------------------------- |
| `print_frequency_ms` | object | 流式更新频率（毫秒），可配置 default/android/ios/pc   |
| `print_step`         | object | 流式更新步长（字符数），可配置 default/android/ios/pc |
| `print_strategy`     | string | 流式更新策略：`fast`/`delay`                      |

**summary (摘要配置)**:

| 字段             | 类型   | 说明                 |
| ---------------- | ------ | -------------------- |
| `content`      | string | 自定义摘要信息       |
| `i18n_content` | object | 摘要信息的多语言配置 |

**style (样式配置)**:

| 字段          | 类型   | 说明                                    |
| ------------- | ------ | --------------------------------------- |
| `text_size` | object | 自定义字号，可配置 default/pc/mobile    |
| `color`     | object | 自定义颜色，可配置 light_mode/dark_mode |

**width_mode 枚举值**:

| 值          | 说明                                             |
| ----------- | ------------------------------------------------ |
| `default` | 默认宽度，PC 端宽版、iPad 端上的宽度上限为 600px |
| `compact` | 紧凑宽度 400px                                   |
| `fill`    | 自适应屏幕宽度                                   |

**JSON 示例**:

```json
{
  "config": {
    "update_multi": true,
    "streaming_mode": false,
    "enable_forward": true,
    "width_mode": "fill",
    "summary": {
      "content": "自定义摘要内容"
    },
    "style": {
      "text_size": {
        "cus-0": {
          "default": "medium",
          "pc": "medium",
          "mobile": "large"
        }
      },
      "color": {
        "cus-0": {
          "light_mode": "rgba(5,157,178,0.52)",
          "dark_mode": "rgba(78,23,108,0.49)"
        }
      }
    }
  }
}
```

### 2.3 card_link (卡片全局跳转链接)

`card_link` 字段用于指定卡片整体的点击跳转链接。你可以配置一个默认链接，也可以分别为 PC 端、Android 端、iOS 端配置不同的跳转链接。

| 字段            | 类型   | 必填 | 说明                 |
| --------------- | ------ | ---- | -------------------- |
| `url`         | string | 否   | 默认的链接地址       |
| `pc_url`      | string | 否   | PC 端的链接地址      |
| `ios_url`     | string | 否   | iOS 端的链接地址     |
| `android_url` | string | 否   | Android 端的链接地址 |

**注意事项**：

- `url` 和各端的链接（`android_url`、`ios_url`、`pc_url`）必填其中一个
- 如果不填写 `url`，则必须完整填写 `android_url`、`ios_url`、`pc_url` 三个字段
- 如果同时填写了 `url` 和各端链接，`url` 字段优先级更高
- 如果需要禁止某端进行跳转，可以将对应的参数值配置为 `lark://msgcard/unsupported_action`

**JSON 示例**:

```json
{
  "card_link": {
    "url": "https://example.com",
    "pc_url": "https://example.com/pc",
    "ios_url": "https://example.com/ios",
    "android_url": "https://example.com/android"
  }
}
```

### 2.4 Header (卡片头部)

`header` 字段用于配置卡片的标题，支持添加卡片主标题、副标题、后缀标签和标题图标。

| 字段              | 类型      | 必填 | 默认值      | 说明                            |
| ----------------- | --------- | ---- | ----------- | ------------------------------- |
| `title`         | TextObject | 是   | -           | 头部主标题（文本对象）          |
| `subtitle`      | TextObject | 否   | -           | 头部副标题（文本对象）          |
| `icon`          | object    | 否   | -           | 头部图标配置                    |
| `template`      | string    | 否   | `default` | 标题主题样式颜色                |
| `text_tag_list` | array     | 否   | -           | 标题后缀标签，最多设置 3 个标签 |
| `padding`       | string    | 否   | `12px`    | 头部内边距，支持范围 [0,99]px   |

**TextObject (文本对象)**:

`title` 和 `subtitle` 字段为文本对象，支持两种模式：

| 字段        | 类型   | 必填 | 说明                                                                 |
| ----------- | ------ | ---- | -------------------------------------------------------------------- |
| `tag`     | string | 是   | 文本类型标签：`plain_text`（纯文本）/`lark_md`（富文本）        |
| `content` | string | 否   | 文本内容。主标题最多四行，副标题最多一行，超出用 `...` 省略         |

**lark_md 支持的 Markdown 语法**:

| 名称       | 语法                                      | 说明                 |
| ---------- | ----------------------------------------- | -------------------- |
| @指定人    | `<at id=open_id></at>`                  | @用户                |
| @所有人    | `<at id=all></at>`                      | @所有人              |
| emoji      | 😁😢🌞💼🏆❌✅                              | 直接复制表情         |
| 飞书表情   | `:OK:`                                  | 飞书表情符号         |

**icon (图标配置)**:

| 字段        | 类型   | 必填 | 说明                                                                |
| ----------- | ------ | ---- | ------------------------------------------------------------------- |
| `tag`     | string | 是   | 图标类型：`standard_icon`（图标库）/`custom_icon`（自定义图片） |
| `token`   | string | 否   | 图标库中的图标 token（tag 为 standard_icon 时生效）                 |
| `color`   | string | 否   | 图标颜色（tag 为 standard_icon 时生效）                             |
| `img_key` | string | 否   | 自定义图标的图片 key（tag 为 custom_icon 时生效）                   |

**template (标题主题样式颜色) 枚举值**:

| 值            | 说明     |
| ------------- | -------- |
| `default`   | 默认样式 |
| `blue`      | 蓝色     |
| `wathet`    | 天蓝色   |
| `turquoise` | 青绿色   |
| `green`     | 绿色     |
| `yellow`    | 黄色     |
| `orange`    | 橙色     |
| `red`       | 红色     |
| `carmine`   | 洋红色   |
| `violet`    | 紫罗兰色 |
| `purple`    | 紫色     |
| `indigo`    | 靛青色   |
| `grey`      | 灰色     |

**text_tag_list (标题后缀标签)**:

| 字段           | 类型      | 必填 | 说明                |
| -------------- | --------- | ---- | ------------------- |
| `tag`        | string    | 是   | 固定为 `text_tag` |
| `element_id` | string    | 否   | 元素唯一标识        |
| `text`       | TextObject | 是   | 标签内容（文本对象） |
| `color`      | string    | 否   | 标签颜色            |

**JSON 示例**:

**示例 1：plain_text 模式**

```json
{
  "header": {
    "title": {
      "tag": "plain_text",
      "content": "欢迎使用飞书卡片"
    },
    "subtitle": {
      "tag": "plain_text",
      "content": "这是副标题"
    },
    "template": "blue",
    "icon": {
      "tag": "standard_icon",
      "token": "chat_outlined",
      "color": "blue"
    },
    "text_tag_list": [
      {
        "tag": "text_tag",
        "text": {
          "tag": "plain_text",
          "content": "标签1"
        },
        "color": "blue"
      }
    ],
    "padding": "12px"
  }
}
```

**示例 2：lark_md 模式（支持 Markdown 语法）**

```json
{
  "header": {
    "title": {
      "tag": "lark_md",
      "content": ":Partying:卡片主标题"
    },
    "subtitle": {
      "tag": "lark_md",
      "content": "<at id=all></at> 请关注"
    },
    "template": "blue",
    "icon": {
      "tag": "standard_icon",
      "token": "larkcommunity_colorful"
    }
  }
}
```

### 2.5 Body (卡片主体)

`body` 字段是卡片的正文部分，包含一个名为 `elements` 的数组，用于放置各类组件。

| 字段                   | 类型      | 必填 | 默认值       | 说明                                                          |
| ---------------------- | --------- | ---- | ------------ | ------------------------------------------------------------- |
| `elements`           | Element[] | 是   | -            | 卡片元素列表                                                  |
| `direction`          | string    | 否   | `vertical` | 正文或容器内组件的排列方向：`vertical`/`horizontal`       |
| `padding`            | string    | 否   | `12px`     | 正文或容器内组件的内边距，支持范围 [0,99]px                   |
| `horizontal_spacing` | string    | 否   | `8px`      | 正文或容器内组件的水平间距                                    |
| `horizontal_align`   | string    | 否   | `left`     | 正文或容器内组件的水平对齐方式：`left`/`center`/`right` |
| `vertical_spacing`   | string    | 否   | `8px`      | 正文或容器内组件的垂直间距                                    |
| `vertical_align`     | string    | 否   | `top`      | 正文或容器内组件的垂直对齐方式：`top`/`center`/`bottom` |

> **JSON 2.0 新增**：`body` 字段是 JSON 2.0 新增的结构，`elements` 属性放置在 `body` 层级下。同时新增了一批布局类属性用于控制子元素排列。

**spacing 间距枚举值**:

| 值              | 说明           |
| --------------- | -------------- |
| `small`       | 小间距，4px    |
| `medium`      | 中等间距，8px  |
| `large`       | 大间距，12px   |
| `extra_large` | 超大间距，16px |
| `[0,99]px`    | 自定义间距值   |

> **注意**：与 1.0 结构相比，`large` 从 16px 变更为 12px，新增 `extra_large` 为 16px。

**JSON 示例**:

```json
{
  "body": {
    "direction": "vertical",
    "padding": "12px",
    "horizontal_spacing": "8px",
    "vertical_spacing": "8px",
    "horizontal_align": "left",
    "vertical_align": "top",
    "elements": [
      {
        "tag": "plain_text",
        "content": "元素 1"
      },
      {
        "tag": "plain_text",
        "content": "元素 2"
      }
    ]
  }
}
```

### 2.5 基础元素属性 (Base Element)

所有元素都继承以下基础属性：

| 字段           | 类型   | 必填 | 说明                   |
| -------------- | ------ | ---- | ---------------------- |
| `tag`        | string | 是   | 元素标签名（组件类型） |
| `element_id` | string | 否   | 元素唯一标识（JSON 2.0 新增属性，仅允许使用字母、数字和下划线，必须以字母开头，不得超过 20 字符） |
| `margin`     | string | 否   | 外边距（支持范围 [-99,99]px） |

> **JSON 2.0 新增**：所有组件和元素新增 `element_id` 属性，作为操作组件或元素的唯一标识。在同一张卡片内，该字段的值全局唯一。

## 3. 基础元素类型

### 3.1 PlainText (纯文本)

纯文本组件用于展示普通文本内容，支持设置字号、颜色、对齐方式等样式。

> **重要说明**：PlainText 是一种固定 `tag` 为 `plain_text` 的文本对象，用于交互组件的 `placeholder`、`label`、`disabled_tips`、`hover_tips` 等字段。与 TextObject 不同，PlainText 不支持 `lark_md` 模式。

| 字段           | 类型    | 必填 | 默认值      | 说明                               |
| -------------- | ------- | ---- | ----------- | ---------------------------------- |
| `tag`        | string  | 是   | -           | 固定为 `"plain_text"`            |
| `content`    | string  | 是   | -           | 文本内容（最多 100 个字符）        |
| `text_size`  | string  | 否   | `normal`  | 文本大小                           |
| `text_color` | string  | 否   | `default` | 文本颜色                           |
| `text_align` | string  | 否   | `left`    | 文本对齐方式                       |
| `notation`   | boolean | 否   | `false`   | 是否使用 notation 样式（灰色小字） |
| `width`      | string  | 否   | -           | 文本宽度                           |

**text_size (文本大小) 枚举值**:

| 值            | 说明             |
| ------------- | ---------------- |
| `heading-0` | 特大标题（30px） |
| `heading-1` | 一级标题（24px） |
| `heading-2` | 二级标题（20px） |
| `heading-3` | 三级标题（18px） |
| `heading-4` | 四级标题（16px） |
| `heading`   | 标题（16px）     |
| `normal`    | 正文（14px）     |
| `notation`  | 辅助信息（12px） |

**text_align (文本对齐) 枚举值**:

| 值         | 说明     |
| ---------- | -------- |
| `left`   | 左对齐   |
| `center` | 居中对齐 |

### 3.2 Markdown (富文本)

| `icon`       | object | 否   | -           | 前缀图标              |

**支持的 Markdown 语法**:

| 名称       | 语法                                                         | 效果           |
| ---------- | ------------------------------------------------------------ | -------------- |
| 换行       | `<br>` 或 `\n`                                           | 换行           |
| 斜体       | `*斜体*`                                                   | *斜体*       |
| 粗体       | `**粗体**` 或 `__粗体__`                                 | **粗体** |
| 删除线     | `~~删除线~~`                                               | ~~删除线~~    |
| 超链接     | `[文本](链接)`                                             | [文本](链接)      |
| 图片       | `![hover_text](image_key)`                                 | 显示图片       |
| 分割线     | `---`                                                      | 水平分割线     |
| 无序列表   | `- 项目`                                                   | 无序列表       |
| 有序列表   | `1. 项目`                                                  | 有序列表       |
| 引用       | `> 引用内容`                                               | 引用块         |
| 代码块     | ` ```语言\n代码\n``` `                                     | 代码块         |
| @指定人    | `<at id=open_id></at>`                                     | @用户名        |
| @所有人    | `<at id=all></at>`                                         | @所有人        |
| 彩色文本   | `<font color='red'>文本</font>`                            | 彩色文本       |
| 标签       | `<text_tag color='blue'>标签</text_tag>`                   | 标签样式       |
| 人员       | `<person id='user_id'></person>`                           | 人员展示       |
| 含图标链接 | `<link icon='chat_outlined' url='https://...'>文本</link>` | 带图标链接     |

**JSON 示例**:

```json
{
  "tag": "markdown",
  "content": "**粗体文本**\n*斜体文本*\n- 列表项 1\n- 列表项 2\n[链接](https://example.com)",
  "text_size": "normal",
  "text_align": "left"
}
```

| `placeholder`    | PlainText | 否   | -           | 占位文本（固定 plain_text 模式）                   |
| `default_value`  | string    | 否   | -           | 默认值                                             |

## 7. 交互行为类型

交互行为用于定义组件被点击或操作时的响应动作。在 JSON 2.0 结构中，通过 `behaviors` 数组配置交互行为。

> **重要变更**：JSON 2.0 结构使用 `behaviors` 数组统一配置交互行为，替代了 1.0 结构中的 `url`、`multi_url`、`value` 等分散属性。

### 7.1 CallbackBehavior (回调行为)

回调行为用于将数据回传到开发者配置的服务器。

| 字段      | 类型   | 必填 | 说明                       |
| --------- | ------ | ---- | -------------------------- |
| `type`  | string | 是   | 固定为 `"callback"`      |
| `value` | object | 否   | 回传数据，支持 object 类型 |

**JSON 示例**:

```json
{
  "type": "callback",
  "value": {
    "action": "submit",
    "data": {
      "id": 123
    }
  }
}
```

---

### 7.2 OpenUrlBehavior (打开 URL 行为)

打开 URL 行为用于点击后跳转到指定的链接地址。

| 字段            | 类型   | 必填 | 说明                  |
| --------------- | ------ | ---- | --------------------- |
| `type`        | string | 是   | 固定为 `"open_url"` |
| `default_url` | string | 是   | 兜底跳转地址          |
| `android_url` | string | 否   | 安卓端跳转地址        |
| `ios_url`     | string | 否   | iOS 端跳转地址        |
| `pc_url`      | string | 否   | PC 端跳转地址         |

**注意事项**:

- 超链接必须包含 schema 才能生效，目前仅支持 HTTP 和 HTTPS
- 如果需要禁止某端进行跳转，可以将对应的参数值配置为 `lark://msgcard/unsupported_action`

**JSON 示例**:

```json
{
  "type": "open_url",
  "default_url": "https://example.com",
  "pc_url": "https://example.com/pc",
  "ios_url": "lark://msgcard/unsupported_action",
  "android_url": "https://example.com/android"
}
```

## 8. 二次确认弹窗

二次确认弹窗用于在用户提交时弹出确认提示，只有用户点击确认后，才执行相应的操作。

| 字段      | 类型      | 必填 | 说明                              |
| --------- | --------- | ---- | --------------------------------- |
| `title` | PlainText | 是   | 弹窗标题（固定 plain_text 模式）  |
| `text`  | PlainText | 是   | 弹窗正文内容（固定 plain_text 模式） |

**注意事项**:

- `confirm` 字段仅在用户点击包含提交属性的按钮时才会触发二次确认弹窗
- 弹窗默认提供了确认和取消按钮
- `title` 和 `text` 字段为 PlainText 类型，`tag` 固定为 `plain_text`，不支持富文本模式

**JSON 示例**:

```json
{
  "confirm": {
    "title": {
      "tag": "plain_text",
      "content": "确认提交"
    },
    "text": {
      "tag": "plain_text",
      "content": "提交后将无法修改，是否确认提交？"
    }
  }
}
```

## 9. 组件嵌套规则

### 9.1 父组件可包含的子元素

| 父组件               | 可包含的子元素                                                                                               |
| -------------------- | ------------------------------------------------------------------------------------------------------------ |
| Card Body            | 所有元素类型                                                                                                 |
| Div                  | 所有元素类型                                                                                                 |
| Column               | 所有元素类型（除表单容器和表格外）                                                                           |
| Form                 | Input, Select, DatePicker, PickerTime, PickerDatetime, Checkbox, Button, Div, PlainText, Markdown, ColumnSet |
| ColumnSet            | Column                                                                                                       |
| InteractiveContainer | 所有元素类型（除表单容器和表格外）                                                                           |
| CollapsiblePanel     | 所有元素类型（除表单容器和表格外）                                                                           |

> **JSON 2.0 变更说明**：表单容器、交互容器、折叠面板、分栏组件可内嵌除表单容器（form）和表格组件（table）外的其它所有组件。这与 1.0 结构有显著差异。

### 9.2 元素可嵌套的父组件

| 元素类型       | 可嵌套在                          |
| -------------- | --------------------------------- |
| PlainText      | Card Body, Div, Column, Form      |
| Markdown       | Card Body, Div, Column, Form      |
| Div            | Card Body, Div, Column, Form      |
| Button         | Card Body, Div, Column, Form      |
| Input          | Card Body, Column, Form           |
| Select         | Card Body, Column, Form           |
| DatePicker     | Card Body, Column, Form           |
| PickerTime     | Card Body, Column, Form           |
| PickerDatetime | Card Body, Column, Form           |
| Checkbox       | Card Body, Column, Form           |
| Image          | Card Body, Div, Column, Form      |
| Table          | Card Body（不可嵌套在其他组件内） |

### 9.3 嵌套层级限制

- 容器类组件最多支持嵌套五层组件
- 建议避免多层嵌套，会压缩内容的展示空间，影响卡片的展示效果

## 附录 D. JSON 2.0 版本更新说明

本节介绍卡片 JSON 2.0 版本与 1.0 版本结构之间的不兼容变更和优化说明。

### D.1 JSON 全局结构变更

**结构变更**：
- JSON 2.0 版本新增 `body` 字段，`elements` 属性放置在 `body` 层级下
- JSON 2.0 版本不再支持通过 `i18n_elements` 字段设置全局多语言，需通过 `i18n_content` 等局部多语言字段实现组件级别的多语言配置

**fallback 字段变更**：
- JSON 2.0 版本暂不支持使用 `fallback` 字段配置自定义的全局降级规则

**默认值变更**：
- JSON 2.0 版本中的 `update_multi` 默认值变更为 `true`，且暂时仅支持设为 `true`

### D.2 容器类组件布局属性默认值变更

**表单容器**：
- `vertical_spacing` 和 `horizontal_spacing` 字段的默认值由 `16px` 改为 `12px`

**交互容器**：
- `vertical_spacing` 默认值由 `12px` 改为 `4px`
- `horizontal_spacing` 默认值由 `12px` 改为 `8px`

### D.3 标题组件配置变更

标题组件的 icon 配置结构变更，统一为：

```json
{
  "header": {
    "title": {},
    "icon": {
      "tag": "standard_icon",
      "token": "chat-forbidden_outlined",
      "color": "orange",
      "img_key": "img_v2_38811724"
    }
  }
}
```

### D.4 图片组件变更

- 不再支持 `stretch_without_padding` 通栏配置
- 可设置 `margin` 字段为负数实现通栏效果：
```json
{
  "tag": "img",
  "img_key": "img_v3_0238_073f1823-df2b-4377-86c6-e293f183622j",
  "size": "crop_center",
  "margin": "4px -12px"
}
```

### D.5 富文本（Markdown）组件变更

**废弃差异化跳转语法**：
- 2.0 结构不再支持 `href` 字段配置的差异化跳转语法
- 使用 `<link></link>` 标签替代：
```json
<link icon='chat_outlined' url='https://example.com' pc_url='' ios_url='' android_url=''>跳转文本</link>
```

**支持标准 Markdown 语法**：
- 支持除 `HTMLBlock` 外所有标准的 Markdown 语法
- 支持部分 HTML 语法：`<br>`、`<hr>`、`<person>`、`<local_datetime>`、`<at>`、`<a>`、`<text_tag>`、`<raw>`、`<link>`、`<font>`

### D.6 新增属性

**streaming_mode 属性**：
- 支持卡片流式更新、文本流式更新能力

**element_id 属性**：
- 所有组件和元素新增 `element_id` 属性
- 作为操作组件或元素的唯一标识
- 仅允许使用字母、数字和下划线，必须以字母开头，不得超过 20 字符

**布局类属性**：
- 组件统一新增 `margin`、`padding`、`direction`、`horizontal_spacing`、`vertical_spacing`、`horizontal_align`、`vertical_align` 等布局属性

### D.7 容器类组件嵌套规则变更

JSON 2.0 结构中：
- 表单容器、交互容器、折叠面板、分栏组件可内嵌除表单容器（form）和表格组件（table）外的其它所有组件

| 1.0 结构 | 2.0 结构 |
| --- | --- |
| 表单容器：不支持内嵌表格、图表、和表单容器组件；不可直接内嵌普通文本组件 | 表单容器可内嵌除表单容器和表格外的所有组件 |
| 交互容器：仅支持内嵌普通文本、富文本、图片、备注、分栏、勾选器、交互容器组件 | 交互容器可内嵌除表单容器和表格外的所有组件 |
| 折叠面板：不支持内嵌表单容器和表格组件 | 折叠面板可内嵌除表单容器和表格外的所有组件 |
| 分栏：不支持内嵌表格、表单和多图混排组件 | 分栏可内嵌除表单容器和表格外的所有组件 |
